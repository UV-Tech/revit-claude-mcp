# Roadmap

## 2.x Stability

- Add structured integration tests for the MCP server.
- Split tool registration into modules by domain.
- Add request IDs and structured logs for the Revit bridge.
- Improve CSV parsing with quoted fields and escaped delimiters.
- Add more dry-run support to bulk write tools.

## Installer and Releases

- Add signed release packages.
- Add a guided installer for non-developers.
- Publish versioned GitHub releases with checksums.
- Add automatic addin manifest generation.

## Revit Capability Expansion

- View filters and graphic overrides.
- Sheet set management.
- Family loading and type catalog helpers.
- Parameter schema export/import.
- Worksharing health checks.
- Model audit reports for warnings, links, imports, and unused content.

## Ecosystem

- Example prompts for architects, BIM managers, engineers, and contractors.
- Sample models or mock bridge tests that do not require Revit.
- Community tool recipes.
